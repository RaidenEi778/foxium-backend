# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-10-01

### Added
- Initial public release.
- JWT-based authentication (register, login, profile).
- Users, points and leaderboard endpoints.
- Courses CRUD for teachers/admins.
- Homework lifecycle: assign, submit, review, grade with automatic point credit.
- Game score logging with automatic point credit.
- Rewards catalog and point-based claiming.
- Admin endpoints for platform-wide stats and user/course/homework management.
- Demo account seed script.
